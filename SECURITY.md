# Security Policy

## Supported versions

Security fixes are made on the latest published version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, especially one that
could expose Vault paths, note contents, or credentials. Use GitHub's private
security-advisory reporting feature for this repository, or contact the
maintainer privately through the repository profile. Include a minimal,
redacted reproduction and impact assessment.

The project will acknowledge the report, assess it, and coordinate a fix before
public disclosure when appropriate.
